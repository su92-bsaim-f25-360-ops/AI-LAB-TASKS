# AI Lab Tasks

Lab work for my Artificial Intelligence course. Each lab is in its own folder with the source code, input data, captured outputs, a README with run commands and a written report (`.docx`).

| Folder | Topic | What it covers |
|--------|-------|----------------|
| [lab1](lab1) | AI foundations | Sourced AI timeline, rule-based eligibility with tests, conversational-test comparison |
| [lab2](lab2) | Agents and environments | PEAS specifications, environment classification, stateful controller |
| [lab3](lab3) | Uninformed search | BFS/DFS traces, DLS/IDDFS, uniform-cost search on a weighted graph |
| [lab4](lab4) | Informed search | A* vs UCS, heuristic audit, overestimate experiment |

## How to run
All code uses Python 3.8+ and the standard library only (no packages to install). Open a lab folder and follow the commands in its `README.md`.

## Notes
- All graphs, thresholds, weights and data are synthetic lab assumptions.
- No credentials or private data are stored in this repository.
